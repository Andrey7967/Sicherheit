# Лабораторная работа № 5

DES в режиме CBC, вариант 25. Основная программа самостоятельно реализует DES и CBC; стандартная криптография используется только в тестах для независимого сравнения.

## Запуск

Нужен Go 1.20 или новее. Из папки проекта:

```powershell
go run .
go run . -text "ABCDEFGHABCDEFGH12345678"
go run . -text "Привет, мир!" -bit 10
go test -v ./...
go vet ./...
```

Без параметров программа запрашивает одну строку; пустая строка выбирает демонстрационный пример. `-text` задаёт текст, `-key` — ключ из 16 HEX-символов, `-bit` — индекс изменяемого бита с нуля, от старшего бита первого байта. Индекс должен находиться внутри шифрограммы с дополнением PKCS#7. По умолчанию ключ `133457799BBCDFF1`, индекс `10`.

Датчик варианта 25: строка 5 таблицы лабораторной № 3, A=21, C=33, T(0)=20, B=256. Принята выдача состояния до его обновления: IV составлен из T(0)…T(7) и равен `14C54A3350B1A6BF`. Методичка не определяет, включать ли начальное состояние; выбранное соглашение явно описано в отчёте.

## Результат сверки с методичкой

Все требования лабораторной № 5 представлены: DES CBC, начальный вектор от датчика лабораторной № 3, ввод текста, шифрование и восстановление, инверсия одного бита и сравнение, опыт с одинаковыми 64-битовыми блоками. Исходные численные результаты подтверждены запуском; основной алгоритм исправлений не потребовал.

Доработаны подробные объяснения, ГСА с русскими командами без конструкций языка программирования, описание запуска и полнота проверок. Добавлен файл модуля для обычного запуска `go run .` и `go test ./...`.

Проверки охватывают известный вектор DES, 40 сравнений CBC со стандартной библиотекой, IV варианта, точное положение ошибки после изменения каждого бита первых двух блоков, полный цикл для пустого текста и UTF-8, повреждение IV и последнего блока, некорректные входные данные и дополнение. Фиксированный учебный IV воспроизводит условия опыта; CBC не проверяет целостность сообщения.
